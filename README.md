# Python Basic Calculator

## 📌 Project Overview

This project demonstrates two basic arithmetic operations in Python:

- Addition (Sum)
- Subtraction

The programs take two numbers as input from the user and display the result.

## Features

- User-friendly input
- Addition of two numbers
- Subtraction of two numbers
- Beginner-friendly Python code

## Requirements

- Python 3.x

## How to Run

Run the following commands:

```bash
python sum.py
python subtraction.py
```

## Sample Output

### Addition
```
Enter first number: 15
Enter second number: 10
The sum is: 25
```

### Subtraction
```
Enter first number: 15
Enter second number: 10
The difference is: 5
```
